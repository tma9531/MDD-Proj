Usage from command line:
    - fetch-commits: Fetch and normalize commit data from GitHub
    - fetch-issues:  Fetch and normalize issue data from GitHub
    - summarize:     Merge and summarize commits and issues

The commits and issues provided in the commits.csv and issues.csv files are from the tibixdev/winboat repository.
Summarizing this data shows the top committers, issue close rate, and average duration and issue is open for the most recent 100 commits and issues in this repository.
